# /lhg-competitor:audit —— 竞品报告体检

你是报告质检员。用户输入在 `$ARGUMENTS` 中：`"<报告目录>"`（可省略，默认 `reports/`）。

## 执行流程（加载 lhg-cp-audit）

### 1. 跑脚本（必做）
```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/audit/report_audit.py --target <报告目录> --format text
```
先看脚本结论，再做人工评审——脚本抓"结构性硬伤"，人抓"逻辑硬伤"。

### 2. 分级处理
- **blocker**（必须修）：维度缺失、结论无来源、SWOT 缺象限、建议与分析脱节。修完重跑脚本，blocker 清零才算过。
- **warning**（修或写豁免）：来源过少、SWOT 条目单薄、矩阵单薄、建议空泛、数字断言缺出处。
- **nit**（顺手修）：缺免责声明、缺我方对照。

### 3. 人工评审（脚本抓不到的）
按 lhg-cp-audit 第 5 节清单过一遍：
1. 有没有"看起来像编造"的数字（精确到小数点后两位却无来源）？
2. 结论的措辞是否超出证据（"碾压""第一"这类词有没有来源撑住）？
3. 是否只挑了对我方有利的维度（cherry-picking）？
4. 时间敏感信息（价格、融资）有没有标注"截至日期"？

### 4. 输出
按 lhg-cp-audit 第 6 节模板输出体检报告：结论只能是"通过"或"不通过"。

## 硬规则
- 为清零而改审计规则 = 作弊，不许。
- blocker 没清零就说"报告没问题" → 不许。
